# Employee Attrition Predictor

A two-service employee attrition prediction application. The Spring Boot service provides the public API and forwards validated employee data to a Python Flask machine-learning service.

## Architecture

- **Spring Boot service**: `http://localhost:8080`
  - Public prediction endpoint: `POST /api/predict`
  - Validates incoming employee data.
- **Python Flask service**: `http://localhost:5000`
  - Prediction endpoint: `POST /predict`
  - Health endpoint: `GET /health`
  - Loads a trained Logistic Regression model and scaler from `.pkl` files.

## Prerequisites

- Java 17 or later
- Maven 3.8 or later
- Python 3.9 or later
- A training dataset named `data.csv`

## Python Service Setup

Open PowerShell in `python-service`:

```powershell
cd python-service
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Place `data.csv` in `python-service`, then train the model:

```powershell
python train_logistics.py
```

Training creates these files in `python-service`:

- `attrition_logistic_model.pkl`
- `data_scaler.pkl`

Start the Flask service:

```powershell
python app.py
```

The Python service must be running before making a prediction through Spring Boot.

## Spring Boot Service Setup

Open a second PowerShell window in `springboot-service`:

```powershell
cd springboot-service
mvn spring-boot:run
```

The service listens on port `8080` and calls the Python service at:

```text
http://localhost:5000/predict
```

To change the upstream URL or Spring Boot port, edit `src/main/resources/application.properties`.

## API Usage

Send a prediction request to the Spring Boot API:

```powershell
$body = @'
{
  "age": 35,
  "monthlyIncome": 8000,
  "department": "Research & Development",
  "jobRole": "Manager",
  "overTime": "No",
  "distanceFromHome": 5,
  "maritalStatus": "Married",
  "gender": "Female",
  "totalWorkingYears": 10,
  "yearsAtCompany": 8
}
'@

Invoke-RestMethod -Method Post `
  -Uri "http://localhost:8080/api/predict" `
  -ContentType "application/json" `
  -Body $body
```

A successful response has this shape:

```json
{
  "prediction": "STAY",
  "turnoverProbability": 0.1234,
  "retentionProbability": 0.8766
}
```

## Accepted Values

- `department`: `Human Resources`, `Research & Development`, `Sales`
- `jobRole`: `Healthcare Representative`, `Human Resources`, `Laboratory Technician`, `Manager`, `Manufacturing Director`, `Research Director`, `Research Scientist`, `Sales Executive`, `Sales Representative`
- `overTime`: `Yes`, `No`
- `maritalStatus`: `Divorced`, `Married`, `Single`
- `gender`: `Female`, `Male`
- `age`: integer from `18` to `65`
- `distanceFromHome`: integer from `0` to `100`
- `totalWorkingYears`: integer from `0` to `50`
- `yearsAtCompany`: integer from `0` to `50`, and no greater than `totalWorkingYears`
- `monthlyIncome`: positive number

Invalid requests return HTTP `400` with validation details. Unexpected service failures return HTTP `500`.
